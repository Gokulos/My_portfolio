# AI / Machine Learning Portfolio

A responsive, static portfolio website designed for GitHub Pages.

## 1. Personalize before publishing
Search the files for `Your Name`, `YOUR NAME`, and `YOUR.EMAIL@example.com`, then replace them with your details.

Also update:
- Your exact Master's programme name, dates, expected graduation, relevant modules and thesis topic.
- Your Bachelor's dates and any relevant coursework or academic achievements.
- LinkedIn and GitHub profile URLs.
- Project cards with real projects, repository links, outcomes and metrics.
- The skills section: remove anything you have not used and add tools you can confidently discuss.
- Add a downloadable CV PDF if you want (for example, place it in `assets/` and link it from the hero).

## 2. Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## 3. Publish with GitHub Pages
1. Create a new public repository on GitHub, e.g. `ai-portfolio`.
2. Upload the contents of this folder (the `index.html`, `style.css`, `script.js`, and `assets/` folder) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/ai-portfolio/`.

For a user site, name the repository `YOUR-GITHUB-USERNAME.github.io`; the URL will then be `https://YOUR-GITHUB-USERNAME.github.io/`.

## Content integrity
This starter does not invent employment history, project results, language proficiency or certifications. The project cards are explicitly marked as project ideas. Replace them with work you have actually completed before applying.
